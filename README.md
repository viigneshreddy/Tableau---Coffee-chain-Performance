# Coffee Chain Performance Analysis

## Overview

This repository contains a Tableau workbook (`.twbx`) that provides a comprehensive performance analysis of a coffee chain. The dashboard visualizes key business metrics to help stakeholders understand sales trends, product performance, and regional insights across the chain's operations.

## File

| File | Description |
|------|-------------|
| `Coffee Chain Performance Analysis.twbx` | Packaged Tableau workbook containing all dashboards, data sources, and visualizations |

## What's Inside

The Tableau workbook includes interactive dashboards and visualizations covering:

- **Sales Performance** – Revenue trends over time, comparisons across periods
- **Product Analysis** – Best and worst performing products by category and type
- **Regional Breakdown** – Geographic performance across different markets and store locations
- **Profitability Metrics** – Margin analysis, cost vs. revenue breakdowns
- **KPI Tracking** – Key performance indicators such as total sales, profit, and units sold

## Requirements

To open and interact with this workbook, you will need:

- [Tableau Desktop](https://www.tableau.com/products/desktop) (version 2020.1 or later recommended)
- **OR** [Tableau Public](https://public.tableau.com/) (free) for basic viewing

## Getting Started

1. Clone or download this repository
2. Open Tableau Desktop or Tableau Public
3. Navigate to **File → Open** and select `Coffee Chain Performance Analysis.twbx`
4. Explore the dashboards using the tabs at the bottom of the workbook

## Data Source

The workbook uses a packaged data source (included within the `.twbx` file), so no external database connection is required.

## Usage

This analysis is intended for:

- Business analysts reviewing coffee chain performance
- Management teams making data-driven decisions
- Data visualization reference and learning
